The match-count ranking does not agree with the pose ranking overall; by tier: tier 1 differs, tier 2 differs, tier 3 differs. (Dense and sparse match counts count different things and are not compared as if equal.) Spearman correlation between per-pair inlier ratio and pose accuracy: SIFT + MNN 0.64; SuperPoint + LightGlue 0.63; LoFTR 0.64.

\paragraph{Rotation tiers.} The tiers split the test pairs by ground-truth rotation only (tier 1 = smallest rotation of the test set), so they are rotation tiers, not a complete difficulty scale. AUC@10 by tier: tier 1 (29--31$^\circ$): SIFT+MNN 0.11, SP+LG 0.76, LoFTR 0.87; tier 2 (32--36$^\circ$): SIFT+MNN 0.06, SP+LG 0.59, LoFTR 0.72; tier 3 (36--58$^\circ$): SIFT+MNN 0.05, SP+LG 0.63, LoFTR 0.79. The ranking is the same in every tier.

\paragraph{Disagreement and complementarity.} Here a pair counts as solved by a matcher if its median pose error over the RANSAC seeds is below $10^\circ$, and $D_{ab}$ is the fraction of the pairs in a tier on which exactly one of the two matchers solves it (denominator: all pairs in the tier). $D_{ab}$ by tier, from the smallest to the largest rotation (pairs in parentheses): SIFT+MNN/SP+LG: 0.82 (28/34), 0.67 (22/33), 0.76 (25/33); SIFT+MNN/LoFTR: 0.85 (29/34), 0.79 (26/33), 0.88 (29/33); SP+LG/LoFTR: 0.03 (1/34), 0.12 (4/33), 0.12 (4/33). In the largest-rotation tier 1 pairs are solved by no matcher, 4 by exactly one, 25 by two and 3 by all three (pairs solved only by SIFT+MNN / SP+LG / LoFTR: 0 / 0 / 4). A best-of-three oracle, which picks the best matcher per pair using the ground truth, reaches AUC@5 0.691, AUC@10 0.815, AUC@20 0.896.
